モデルの中身

1. 音響等価回路

pin は音孔入口の音圧。音孔は管の音響質量 Mp と粘性抵抗 Rp(f)、前室は空気ばね Cf = Vf/γP0。前室と背室 (Cbv) の間に、ダイアフラム枝とベント枝 Rv が並列に入ります。ダイアフラム枝はピストン近似で、質量 Md = ρdh/A、静電ばね軟化を含むコンプライアンス Cd、バックプレート隙間のスクイーズ膜抵抗 Rsq、孔の流路抵抗 Rh と質量 Mh の直列です。

2. 雑音の合成

揺動散逸定理により、各音響抵抗 R には直列に圧力雑音源 4kTR [Pa²/Hz] が付きます。2節点（前室・背室）の節点方程式を周波数ごとに解き、ダイアフラム体積速度 Ud への伝達関数 Hi を音源からの伝達 Hsig で割って入力に換算します。電気雑音はゲート点の電圧感度 Sg で割ります。

Sin(f) = Σi 4kTRi·|Hi/Hsig|² + [4kT/Rb·|Zn|² + in²|Zn|² + en²(1+fc/f) + eo²/G²] / |Sg|²
Sg = Hsig·(VbC0/g0A)·Zn　　Zn = Rb/(1+jωRbCtot)　　Ctot = C0+Cp+Cin
NA = 10·log10[∫2020k Sin(f)·|WA(f)|² df / (20 µPa)²]　　SNR = 94 − NA
3. 前提と限界
  • 集中定数近似のため、波長がパッケージ寸法と同程度になる帯域（概ね 50 kHz 以上）では精度が落ちます。
  • ダイアフラムは一様変位のピストンとして扱います。クランプ膜では実効面積・実効質量の補正係数が必要です。sm は「背室なし・バイアスなし」での平均変位感度と定義しています。
  • バイアスによる静的たわみと非線形性は無視し、静電ばね軟化のみ線形化して含めています。Vb が VPI に近いと実機より楽観的になります。
  • 背室・前室の熱境界層損失（等温/断熱遷移による雑音）と、ダイアフラム自体の構造減衰は含めていません。小背室ではこれらが無視できなくなります。
  • デジタルマイクの ΔΣ 変調器・デシメーションは、白色の出力換算雑音 eo だけで代表しています。
  • 物性: 空気は温度 T の理想気体、μ は Sutherland 式、ダイアフラム密度 2330 kg/m³（ポリシリコン）。
