# MEMS Microphone Noise Model

容量型 MEMS マイクロホンの集中定数等価回路モデルから、入力換算ノイズフロアと SNR をブラウザ上でシミュレーションするツールです。

`index.html` をブラウザで開くだけで動きます（ビルド不要、Google Fonts 以外の外部依存なし）。

## モデル

- **音響系**（インピーダンス類推: 圧力↔電圧、体積速度↔電流）
  音孔 (R_p, M_p) → 前室 C_f → [ダイアフラム M_d, C_d（静電ばね軟化込み）, スクイーズ膜 R_sq, 孔 R_h, M_h] ∥ ベント R_v → 背室 C_bv
- **電気系**: 定電荷読出し、バイアス抵抗 R_b、寄生容量 C_p、アンプ入力容量 C_in、アンプ e_n (1/f 込み)・i_n、ASIC ゲイン G、出力換算雑音 e_o
- 各音響抵抗に 4kTR の熱雑音源を置き、周波数ごとに 2 節点方程式を解いて入力換算
- 20 Hz–20 kHz の A 特性積分ノイズ N_A と SNR = 94 − N_A を算出

## 主な出力

- 雑音源別の入力換算ノイズスペクトル (dB SPL/√Hz)
- A 特性ノイズへの寄与率、SNR、感度 (dBV/Pa)、共振周波数、低域カットオフ、プルイン余裕
- 現在値入りの等価回路図

前提と限界はページ下部「モデルの中身」に記載しています。

## スプレッドシート版

`mems_noise_model.xlsx` は同じモデルを Excel の数式（COMPLEX / IMDIV / IMPRODUCT などの複素数関数）で実装したものです。

- **Inputs**: プリセット（標準 / 高SNR / 小型）を選択し、黄色の「上書き」列で個別に値を変更
- **Summary**: SNR・感度などの主要指標、雑音源別の寄与表、ノイズスペクトルと周波数特性のグラフ
- **Lumped**: 集中定数の計算
- **Spectrum**: 10 Hz–100 kHz（1デカード100点）の周波数ごとの計算と積分
- **Notes**: 式と前提条件
